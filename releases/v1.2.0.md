# Zona Simple Views 1.2.0

Versi ini menambahkan pengubahan counter melalui **Posts → All Posts → Quick Edit → Zona Views → Update**.

Quick Edit membaca angka terbaru dari server, memeriksa izin administrator/editor serta nonce, dan mempertahankan views otomatis maupun angka impor. Kunjungan yang masuk setelah formulir dibuka tetap ditambahkan. Memperbarui field lain tanpa mengubah angka tidak mereset counter.

Fitur versi 1.1.0 tetap tersedia: teks hitam, impor massal Post Views Counter, pembatasan kategori, dan shortcode `[zsv_views]`.

## Memperbarui plugin

Unduh `zona-simple-views-1.2.0.zip`, unggah melalui **Plugins → Add New → Upload Plugin**, lalu pilih **Replace current with uploaded**. Pengaturan, angka, dan hasil impor tetap tersimpan. Tidak perlu mengimpor ulang views lama. Bersihkan cache situs setelah memperbarui.

Gunakan ZIP plugin yang dilampirkan; arsip **Source code** GitHub memuat seluruh repo.

## Validasi

Lolos pemeriksaan sintaks PHP/JavaScript, pemeriksaan server Quick Edit, simulasi formulir Quick Edit, regresi counter, dan simulasi impor 2.501 artikel beserta impor ulang. Quick Edit belum diuji langsung pada situs produksi pengguna.
